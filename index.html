🔒 레시피북 관리 원칙

규칙 0 · 기존 데이터 임의 삭제 금지

이미 등록된 레시피·원두·팁·사이트·원두사전은 요청 없이 삭제하지 않는다. 수정은 기본적으로 추가·보강 방식으로 진행한다.

중복은 삭제보다 병합

같은 자료가 들어오면 기존 항목과 비교해서 보강한다. 하나를 없애야 하는 경우 먼저 확인한다.

공식값과 추천값 분리

로스터가 공개한 값은 공식으로 보존하고, 보완한 수치는 추천 시작값으로 명확히 표시한다.

Git 반영 전후 확인

수정 전 기존 항목을 기준으로 작업하고, 반영 후 예상치 못한 항목 감소가 없는지 확인한다.

💡 브루잉 기본 가이드

📅 디개싱 vs 레스팅

디개싱은 로스팅 직후 원두 내부 CO₂가 빠지는 과정. 레스팅은 향미가 더 조화롭고 선명해지도록 기다리는 숙성 개념.

💧 필터 린싱

접합부를 약 0.5cm 접고 물로 충분히 적신다. 종이 냄새 제거·필터 밀착·드리퍼 예열 목적이며 린싱 물은 버린다.

🫘 원두 담기

원두를 담은 뒤 드리퍼를 가볍게 흔들어 평평하게. 세게 두드리면 미분이 아래로 몰릴 수 있어 피한다.

🎯 쓰거나 떫으면

먼저 물을 조금 타서 단순히 진한 건지 확인. 그래도 쓰고 떫다면 다른 조건을 건드리지 말고 분쇄도를 조금 굵게.

🍋 밋밋하거나 찌르듯 시면

과소추출 가능성. 다른 조건은 유지하고 분쇄도를 조금 곱게.

🔧 한 번에 하나만

분쇄도·온도·푸어를 동시에 바꾸지 않는다. 한 변수만 조정하고 맛과 시간을 기록한다.

⏱ 추출시간

시간은 목표 범위이지 절대 규칙은 아님. 너무 빠르면 더 곱게, 너무 느리면 더 굵게 조정하는 것이 기본.

🧊 아이스 마무리

추출 직후 서버를 충분히 저어 빠르게 냉각. 너무 연하면 다음 번 얼음 또는 추출수를 10~20g만 조정.

📏 누적량 먼저 보기

각 단계에서 저울의 목표 숫자를 먼저 확인하고, +양은 실제 추가량 확인용으로 사용.

🧪 추천 시작값 사용법

추천 수치는 정답이 아니라 첫 테스트 지점. 실제 종료시간과 맛을 보고 WaBliss를 1~2칸씩 조정.
